如何从外网/手机公网访问此网页？

选择最适合你的部署与网络穿透方案

🌟 最推荐 · 免费且稳定

方案一：托管到免费静态云平台 (Vercel / GitHub Pages / Cloudflare)

因为本项目是单文件 HTML，直接拖拽或发布即可获得永久免费的 HTTPS 公网域名，手机电脑随时查看。

方法 A：使用 Vercel (最方便拖拽部署)
  1. 注册并登录 vercel.com
  2. 点击 "Add New Project" ➡️ 选择 "Upload"
  3. 把包含 index.html 的文件夹直接拖入浏览器中
  4. 几秒后系统将自动为你生成一个专属公网链接（如 https://your-stock-app.vercel.app）
方法 B：GitHub Pages

在 GitHub 新建 Repository，将 index.html 上传后，进入仓库的 Settings ➡️ Pages，选择 main 分支保存即可。

方案二：内网穿透 (无需公网 IP，在本地电脑运行)

如果网页挂在本地电脑的 Web 服务上（如 Live Server / Nginx），可以使用穿透工具将本地端口映射到公网。

Cloudflare Tunnel (免费/无缝加密)

安装 cloudflared 后运行命令：

cloudflared tunnel --url http://localhost:5500

控制台会输出一个临时公网 URL，手机即可直接访问。

Tailscale (私密组网访问)

在电脑和手机上同时安装 Tailscale 并登录同一账号。手机直接输入电脑在 Tailscale 内网中的 IP 即可在安全加密通道下远程访问。
